# Brain

This vault holds the context Claude's skills use: standing rules, one note
per skill, one note per project, design decisions, and a monthly run log.
Obsidian Git keeps it in sync with GitHub (`Shim-1122/Obsidian`).

> [!info] How skills use it
> Before a skill runs, Claude reads [[Home]], [[Rules]], the skill's note in
> `Skills/`, and the project's note in `Projects/`. Afterwards it adds one
> line to the month's log in `Log/` and records any decisions in the
> project or skill note.

## Layout
- [[Rules]]: rules for every skill
- `Skills/`: one note per skill (template: [[Templates/Skill]])
- `Projects/`: one note per project (template: [[Templates/Project]])
- `Design/<project>/`: design systems and decisions
- `Log/YYYY-MM`: one line per skill run
